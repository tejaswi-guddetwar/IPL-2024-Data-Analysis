IPL 2024 Data Analysis

Project Description

This project analyzes IPL 2024 match data to understand team performance, player contributions, match outcomes, and scoring trends.

Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

Project Files

- IPL data analysis Python code
- Cleaned IPL 2024 dataset (CSV)
- Power BI dashboard
- Business insights report

Key Analysis

- Team-wise match wins
- Top run scorers and wicket takers
- Player of the Match awards
- Toss decisions and match outcomes
- Season-wise runs and match statistics

Conclusion

The project uses data analysis and visualization to present useful insights from IPL 2024 match data.
